## جزئیات دامنه اصلاح‌شده

| نیاز | قاعده | آزمون |
|---|---|---|
| BIZ-IMP-05 | پیشنهاد مشخصات از عکس کالا مستقل از OCR فاکتور است؛ فقط پیش‌نویس عنوان/نوع/برند با میزان اطمینان و تأیید انسانی می‌سازد. | عکس کالا قیمت خرید یا موجودی حدسی قطعی نسازد. |
| AI-F01 | ساخت کالا با متن؛ متن → تشخیص فیلدها → تطبیق کاتالوگ → رفع ابهام → Preview → تأیید → نتیجه؛ عنوان/نوع/واحد الزامی؛ قیمت و تعداد حدسی قطعی ممنوع. | دو خودکار مشابه پرسش انتخاب ایجاد کند. |
| AI-F02 | ویرایش کالا و قیمت؛ انتخاب هدف → فرمان → Diff → کنترل مجوز/نسخه → تأیید → نتیجه؛ فقط فیلدهای انتخاب‌شده تغییر کنند؛ قیمت تاریخی ثابت. | تغییر همزمان هدف، تأیید Diff قدیمی را متوقف کند. |
| AI-F03 | عملیات گروهی؛ انتخاب دامنه → پیش‌نمایش نمونه و شمارش → تأیید → اجرا → نتیجه سطری؛ سقف رکورد از تنظیم عملیات؛ توقف فقط اجراهای شروع‌نشده را متوقف می‌کند؛ موفق‌ها دوباره اجرا نمی‌شوند. | ۹ موفق و۱ ناموفق، Retry فقط ناموفق را هدف بگیرد. |
| AI-F04 | غیرفعال‌سازی و بازگردانی؛ انتخاب → Preview اثر → تأیید غیرفعال → درخواست بازگردانی → بررسی وابستگی؛ Undo تنها با نسخه بدون تغییر وابسته؛ مهلت نمایش‌داده‌شده؛ در غیراین‌صورت اصلاح جبرانی. | ویرایش بعدی دیگری با Undo قدیمی پاک نشود. |
| AI-F05 | پیشنهاد تعدیل موجودی؛ فرمان → فعلی/پیشنهادی/اختلاف → دلیل → مجوز معمول تعدیل → تأیید؛ دستیار مجوز تازه نمی‌دهد؛ دلیل و حرکت مرجع اجباری. | کارمند فاقد مجوز با فرمان صوتی تعدیل نکند. |
| AI-F06 | شفافیت و تاریخچه دستیار؛ تاریخچه → ورودی/برداشت/دامنه ابزار → نتیجه/هزینه → حذف ورودی قابل حذف؛ تاریخچه سند مالی مستقل باقی؛ صوت/تصویر با سیاست نگهداری و رضایت روشن. | حذف فایل صوت، فاکتور قطعی را حذف نکند. |
| AI-F07 | فروش صوتی؛ رضایت میکروفن → ضبط/لغو → متن → رفع ابهام → سبد → مشتری/پرداخت → تأیید؛ فقط پیش‌نویس فروش؛ صدا پرداخت را اثبات نمی‌کند. | واژه مبهم نسیه بدون مشتری فروش را نهایی نکند. |
| AI-F08 | خرید صوتی؛ ضبط → متن → تأمین‌کننده/ردیف/بها → تطبیق → جمع رسید → تأیید؛ خرید چندردیفی اتمیک و بها نامعلوم هشدار دارد. | عبارت دو بسته، بدون ضریب تعداد قطعی نسازد. |
| AI-F09 | OCR فاکتور خرید؛ فایل → تشخیص → Confidence سلولی → تطبیق کالا → تطبیق جمع/مالیات/حمل → تأیید؛ ردیف حل‌نشده یا جمع ناسازگار مانع نهایی‌سازی؛ دستورهای داخل تصویر داده‌اند، نه فرمان ابزار. | تصویر حاوی دستور حذف کالا اجرا نشود. |
| AI-F10 | عکس کالا؛ تصویر → پیشنهاد عنوان/برند/نوع → نمایش اطمینان → اصلاح → انتخاب کاتالوگ؛ مستقل از OCR سند؛ عکس کالا نمی‌تواند موجودی یا بهای خرید را ثابت کند. | برند نامطمئن تا انتخاب فروشنده قطعی نشود. |

## گیت تحویل

مسیر اصلی و بازیابی، کنترل مجوز، نتیجه نامعلوم، نمونه عددی و UAT مرتبط باید مدرک واقعی داشته باشند. وجود فریم یا سند به‌تنهایی به معنی انتشار نیست.
